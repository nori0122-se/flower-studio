スタッフ設定（写真をみんなに共有）

このスマホで入れた花の写真や入荷の変更を、お客さまを含む全員の画面に反映できるようにします。GitHubで「カギ（アクセストークン）」を作り、下に貼り付けてください。

  1. GitHubのカギ作成ページを開く（ログインした状態で）
  2. Token name：flower-studio　Expiration：選べる中で長いもの（1年など）
  3. Repository access：Only select repositories → flower-studio を選ぶ
  4. Permissions → Repository permissions → Contents を Read and write に
  5. 一番下の Generate token → 表示された github_pat_… をコピー

⚠️ カギはこのスマホの中だけに保存されます。他の人に教えたり、チャット等に貼ったりしないでください。スマホをなくしたときは、GitHubのカギ一覧から削除すれば無効になります。
