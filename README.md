# 花束スタジオ サイトの編集マニュアル

このフォルダがウェブサイトの中身です。
**ここのファイルを変えると、数十秒後に公開サイトが自動で新しくなります。**

編集はぜんぶ**ブラウザ（GitHubの画面）だけ**でできます。アプリのインストールは不要です。

---

## ファイルの役割

| ファイル / フォルダ | なにが入っているか |
|---|---|
| `content.json` | **みんなに見せる内容の設定**（花材リスト、作品一覧、文章、注文メール先） |
| `images/flowers/` | 花材の写真（バラ、ガーベラなど） |
| `images/gallery/` | 作品（花束）の写真 |
| `index.html` | アプリ本体。**触らないでください** |

---

## 1. 花材の写真を入れる・差し替える

### ① 写真をアップロードする
1. GitHubで `images` → `flowers` フォルダを開く
2. 右上の **「Add file」→「Upload files」** をクリック
3. 写真をドラッグ＆ドロップ
4. 下の緑のボタン **「Commit changes」** を押す

> **写真の名前のルール**
> - 半角の英数字だけ（例：`bara.jpg`、`gerbera.jpg`）
> - 日本語やスペースは使わない
> - 大きすぎる写真は避ける（スマホ写真をそのままでもOKですが、軽いほど表示が速いです）

### ② どの花の写真か教える
1. `content.json` を開く
2. 右上の **鉛筆マーク（Edit）** をクリック
3. その花の `"photo": ""` の部分に、入れた写真の場所を書く

```
  {
    "jp": "バラ",
    "en": "roses",
    "photo": "images/flowers/bara.jpg"     ← ここに書く
  },
```

4. 下の **「Commit changes」** を押す → 完了

**写真を差し替えたいだけ**なら、同じ名前の写真を上書きアップロードするだけでOKです（`content.json` は触らなくて大丈夫）。

### 金額を付ける
花材の `"price"` に数字だけを書くと、花の名前の下に「300円」のように表示されます（書かなければ表示なし）。

```
    "photo": "images/flowers/bara.jpg",
    "price": 300
```

アプリの画面からも設定できます：
- **追加するとき** … 花の名前の横の「金額」欄に数字を入れて「追加」
- **あとから変えるとき** … 花の下の **「編集」** → 名前・金額を直して「保存」（この花を削除もここから）

### ③ 入荷あり・なしの切り替え（大事）

サイトでは **写真がある花＝入荷中**、**写真がない花＝「現在入荷していません」** と表示され、お客さまは選べなくなります。

- **入荷したとき** … `"photo"` に写真の場所を書く（上の②）
- **売り切れ・入荷が終わったとき** … `"photo": ""` のように **空にする**

```
    "photo": ""        ← 空にすると「入荷なし」表示になる
```

## ★ いちばん簡単：スマホから直接みんなに共有する（スタッフ用）

スタッフのスマホに一度「カギ」を入れると、**アプリの「写真」ボタンで撮った写真が、そのまま全員の画面に反映**されます（上の①②の作業は不要になります）。

### 最初に1回だけ
1. スマホでサイトを開き、花材一覧の右上の **🔑** を押す
2. 画面の案内どおりに GitHub で「カギ（アクセストークン）」を作る
   - Repository access は **flower-studio だけ**、Contents は **Read and write**
3. できたカギ（`github_pat_…`）を貼り付けて **「保存して接続」**
4. 見出しの横に **「共有モード」** と出たら完了

### そのあと
- **写真** … 入荷した花を撮る → 全員に「入荷中」で表示
- **外す** … 売り切れ → 全員に「入荷なし」で表示
- **追加 / 編集** … 花材の追加、名前・金額の変更、削除も全員に反映

お客さまの画面に出るまで **1〜2分** かかります（スタッフのスマホにはすぐ出ます）。

### 注意
- カギは**そのスマホの中だけ**に保存されます。他の人に教えたり、チャットに貼ったりしないでください
- スマホをなくしたら、GitHub の [カギ一覧](https://github.com/settings/personal-access-tokens) からそのカギを削除すれば無効になります
- カギには期限があります。期限が切れたら同じ手順で作り直してください
- カギを入れていないスマホ（お客さまなど）は、見るだけで変更はできません

## ★ 「花束の写真を生成する」を高画質にする（Cloudflare・無料）

アプリ内の画像生成を、高画質なAI（FLUX）に切り替えます。最初に1回だけ設定します。

1. [Cloudflare](https://dash.cloudflare.com/sign-up) で無料アカウントを作る
2. 左のメニューから **Workers & Pages**（または Compute → Workers）を開き、**Create** → **Create Worker**
3. 名前を `flower-studio-image` にして **Deploy**
4. **Edit code** を押し、中身を全部消して、このリポジトリの `cloudflare/worker.js` の中身を貼り付けて **Deploy**
5. Worker の **Settings** → **Bindings** → **Add** → **Workers AI** を選び、Variable name を **`AI`** にして保存（Deploy）
6. Worker の住所（`https://flower-studio-image.○○.workers.dev`）をブラウザで開き、「花束スタジオの画像サーバーは動いています。」と出ればOK
   - 住所の最後に `?prompt=white roses bouquet` を付けて開くと、花束の画像が出ます
7. `content.json` の `"image"` の `"endpoint"` に、その住所を書いて Commit changes

```
  "image": {
    "endpoint": "https://flower-studio-image.○○.workers.dev"
  },
```

- 1日に使える無料分があり、**毎朝9時（日本時間）にリセット**されます。使い切るとその日は生成できなくなるだけで、**料金はかかりません**（無料プランのまま使う場合）
- `endpoint` を空（`""`）に戻すと、元の生成方法に戻ります

## 2. 作品（花束）をギャラリーに載せる

1. 写真を `images/gallery/` にアップロード（手順は上と同じ）
2. `content.json` の `"gallery": []` の中に、次のように書き足す

```
  "gallery": [
    {
      "title": "季節のブーケ",
      "price": "3,300円",
      "photo": "images/gallery/001.jpg",
      "seasons": ["spring"],
      "colors": ["ピンク", "ホワイト"]
    }
  ],
```

- `seasons` は `spring` `summer` `autumn` `winter` から選ぶ（複数OK）
- `colors` は `レッド` `ピンク` `コーラル` `オレンジ` `イエロー` `グリーン` `パープル` `ブルー` `ボルドー` `ホワイト` から選ぶ（複数OK）
- 2つ目以降は `},` と `{` でつなげて並べます

## 3. サイトの文章を変える

`content.json` の `"texts"` に書くと、画面の文章を差し替えられます。

```
  "texts": {
    "ja": {
      "brand.title": "〇〇フラワー",
      "brand.desc": "季節のお花をご提案します。"
    },
    "en": {
      "brand.title": "OO Flower",
      "brand.desc": "Seasonal flowers for every occasion."
    }
  },
```

よく使う名前：`brand.title`（サイト名）、`brand.desc`（説明文）

---

## ⚠️ 大事なルール

- **`,`（カンマ）と `"`（ダブルクォート）を消さない**でください。1つでも欠けるとサイトの内容が読み込めなくなります
- 最後の項目のうしろには `,` を付けません
- 不安なときは、編集画面の **「Preview」** タブで色が付いて見えるか確認してください
- もし壊れてしまっても、GitHubの **「History」** から前の状態に戻せます（元に戻せるので安心してください）

---

## 変更が反映されるまで

**Commit changes を押してから、だいたい30秒〜1分**で公開サイトに反映されます。
反映されないときは、ブラウザの再読み込み（スマホなら一度タブを閉じて開き直し）をしてみてください。
