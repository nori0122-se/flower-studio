# 花束スタジオ サイトの編集マニュアル

このフォルダがウェブサイトの中身です。
**ここのファイルを変えると、数十秒後に公開サイトが自動で新しくなります。**

編集はぜんぶ**ブラウザ（GitHubの画面）だけ**でできます。アプリのインストールは不要です。

---

## ファイルの役割

| ファイル / フォルダ | なにが入っているか |
|---|---|
| `content.json` | **みんなに見せる内容の設定**（花材リスト、作品一覧、文章、注文メール先） |
| `images/flowers/` | 花材の写真（バラ、ガーベラなど） |
| `images/gallery/` | 作品（花束）の写真 |
| `index.html` | アプリ本体。**触らないでください** |

---

## 1. 花材の写真を入れる・差し替える

### ① 写真をアップロードする
1. GitHubで `images` → `flowers` フォルダを開く
2. 右上の **「Add file」→「Upload files」** をクリック
3. 写真をドラッグ＆ドロップ
4. 下の緑のボタン **「Commit changes」** を押す

> **写真の名前のルール**
> - 半角の英数字だけ（例：`bara.jpg`、`gerbera.jpg`）
> - 日本語やスペースは使わない
> - 大きすぎる写真は避ける（スマホ写真をそのままでもOKですが、軽いほど表示が速いです）

### ② どの花の写真か教える
1. `content.json` を開く
2. 右上の **鉛筆マーク（Edit）** をクリック
3. その花の `"photo": ""` の部分に、入れた写真の場所を書く

```
  {
    "jp": "バラ",
    "en": "roses",
    "photo": "images/flowers/bara.jpg"     ← ここに書く
  },
```

4. 下の **「Commit changes」** を押す → 完了

**写真を差し替えたいだけ**なら、同じ名前の写真を上書きアップロードするだけでOKです（`content.json` は触らなくて大丈夫）。

---

## 2. 作品（花束）をギャラリーに載せる

1. 写真を `images/gallery/` にアップロード（手順は上と同じ）
2. `content.json` の `"gallery": []` の中に、次のように書き足す

```
  "gallery": [
    {
      "title": "季節のブーケ",
      "price": "3,300円",
      "photo": "images/gallery/001.jpg",
      "seasons": ["spring"],
      "colors": ["ピンク", "ホワイト"]
    }
  ],
```

- `seasons` は `spring` `summer` `autumn` `winter` から選ぶ（複数OK）
- `colors` は `レッド` `ピンク` `コーラル` `オレンジ` `イエロー` `グリーン` `パープル` `ブルー` `ボルドー` `ホワイト` から選ぶ（複数OK）
- 2つ目以降は `},` と `{` でつなげて並べます

---

## 3. サイトの文章を変える

`content.json` の `"texts"` に書くと、画面の文章を差し替えられます。

```
  "texts": {
    "ja": {
      "brand.title": "〇〇フラワー",
      "brand.desc": "季節のお花をご提案します。"
    },
    "en": {
      "brand.title": "OO Flower",
      "brand.desc": "Seasonal flowers for every occasion."
    }
  },
```

よく使う名前：`brand.title`（サイト名）、`brand.desc`（説明文）

---

## 4. 注文メールの送り先を変える

```
  "order": { "email": "あたらしいアドレス@example.com" },
```

---

## ⚠️ 大事なルール

- **`,`（カンマ）と `"`（ダブルクォート）を消さない**でください。1つでも欠けるとサイトの内容が読み込めなくなります
- 最後の項目のうしろには `,` を付けません
- 不安なときは、編集画面の **「Preview」** タブで色が付いて見えるか確認してください
- もし壊れてしまっても、GitHubの **「History」** から前の状態に戻せます（元に戻せるので安心してください）

---

## 変更が反映されるまで

**Commit changes を押してから、だいたい30秒〜1分**で公開サイトに反映されます。
反映されないときは、ブラウザの再読み込み（スマホなら一度タブを閉じて開き直し）をしてみてください。
